# MBTI Quiz

Test your MBTI knowledge. Interactive **MBTI personality quiz** with around 150 questions.

## 🕹️ Play

**[Play the MBTI Quiz](https://irfankurtagic.github.io/mbti-quiz/)**

## 🌙 Theme

The quiz automatically follows the user's system preference for light or dark mode using CSS `prefers-color-scheme`.

## ✨ Features

* 🧠 Around 150 questions
* 📝 Interactive multiple-choice quiz
* 🎯 MBTI type calculation
* 🏆 High-score tracking
* 🌙 Automatic light/dark theme support
* 📱 Responsive design
* 🔀 Questions stored separately in JSON
* ⚡ No frameworks or external dependencies

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**
* **JSON**

## 💭 About

This project started as a small experiment with **JavaScript, personality quizzes, and interactive web design**.

The goal was to create a simple but enjoyable quiz experience while experimenting with question data stored in JSON, scoring logic, responsive layouts, themes, and persistent high scores.
